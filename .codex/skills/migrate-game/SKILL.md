# Migrate Game

Follow [the shared migration workflow](../../../.agent-workflows/migrate-game.md). It is the provider-neutral source of truth.

Establish preparation from the developer's account and offer preparation instructions unless already addressed. Preserve the existing game and wiki; do not invoke initialization or introduce template-version tracking. Assess compatibility, implement necessary integration changes, update wiki pages in place and verify the actual game.
